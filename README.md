## Описание

Этот проект представляет собой простое приложение для управления заметками, реализованное с использованием принципов
объектно-ориентированного программирования (ООП). Проект был разработан в рамках учебного задания от Pytex.

## Особенности

- Создание, чтение, обновление и удаление заметок (CRUD)
- Хранение данных в формате CSV
- Простой и понятный интерфейс
- Легко расширяемая архитектура

## Требования

- Python 3.6 или выше
- Стандартная библиотека Python (не требует дополнительных зависимостей)

## Использование

1. Клонируйте репозиторий
2. Запустите основной скрипт
3. Следуйте инструкциям в консоли для управления заметками
